# TP Git Intro - WebStart

## Objectif
Apprendre les bases de Git : init, commit, branches, merge, conflit, push/pull.

## Technologies utilisées
- HTML / CSS
- Git et GitHub
- VS Code

## Comment ouvrir la page
Ouvrir `index.html` dans un navigateur ou avec Live Server dans VS Code.

## Évolutions enregistrées dans Git
1. Ajout du style expérimental noir sur branche `nouveau-style`
2. Ajout du slogan WebStart et gestion du conflit sur `slogan-a`
3. Ajout de la documentation README
